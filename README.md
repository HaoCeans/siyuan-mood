# 心情管理（siyuan-mood）

一个给[思源笔记](https://b3log.org/siyuan)用的心情插件：用随机问答记录**此刻**的状态，交给思源自带的 AI 解读，跟进建议的实际效果，并看长期趋势。

> 完全离线、数据永久保留在你自己的工作空间里、只用思源原生 AI。

## 功能

**1. 随机心情问答**
内置 24 道只问「此刻」的题，覆盖五个维度：身体觉察、情绪识别、能量状态、情绪回避、当下需求。每次按维度分层随机抽 10 题，单选与多选混合。每次问答都是一张卡片：日期、心情分、关键词、AI 状态、跟进进度。

**2. AI 解读，用思源自己的 AI**
插件不保存任何密钥，走内核的 `/api/ai/chatGPT`，也就是你在**设置 → AI → 编辑模型**里配好的那个模型。解读给出：一句话的状态概括、3-5 个关键词、2-3 条能在 10 分钟内做完的小动作、以及这几天可以试的一个练习。从第二次开始，提示词里会带上你上次的建议做了没有、做完感觉如何，所以建议会跟着你调整，而不是每次重复一遍。

**3. 跟进闭环，不只是建议**
每条建议下面有三个按钮——做了 / 部分做了 / 没做；选「没做」会追问卡在哪（忘了 / 太难 / 不想做 / 没时间 / 其他），选「做了」会追问照做之后的心情（1-5）和一句真实感受。**「没做」是数据，不是失败**，它会进入下一次解读，让 AI 把建议调得更可执行。

**4. 统计**
心情曲线（带移动平均）、维度雷达（本次 vs 均值）、最近 12 周日历热力、关键词频次、可导出 CSV 的记录表格，以及任意周期的一段 AI 心情卡片。

**5. 跟着曲线走的提醒**
间隔在本地算（基础 7 天）：曲线往下走 → 缩短，波动大 → 缩短，有没跟进的建议 → 缩短，状态稳定且测得够勤 → 拉长，最后夹在你设的最短/最长之间。到期时顶栏图标亮红点并推送一条提示；免打扰时段只更新红点；「今天不再提醒」当天静音。

## 安装

1. 从最新 release 下载 `package.zip`。
2. 解压到 `<工作空间>/data/plugins/siyuan-mood/`。
3. 刷新思源，在 设置 → 集市 → 已下载 中启用「心情管理」。

需要思源 3.8.4 及以上。

## 使用

- 点顶栏的心形图标、打开右侧「心情」面板，或用命令面板里的「开始问答」。
- 答完最后一题即提交并（按设置）自动请求 AI 解读。
- 点任意卡片查看完整作答、AI 解读与建议跟进。
- 侧栏另外两个标签页是统计与表格。

## 数据在哪里

`<工作空间>/data/storage/petal/siyuan-mood/`：

| 文件 | 内容 |
|---|---|
| `settings.json` | 你的设置 |
| `bank.json` | 导入的题库 |
| `index.json` | 列表与统计用的轻索引 |
| `rec-YYYY-MM.json` | 该月的记录明细 |

都是工作空间里的普通 JSON，会随思源同步一起走，也可以直接备份或手改。AI 请求只发往你自己配置的模型，插件不保存凭证、不向其他地方发送任何数据。

## 导入自己的题库

设置 → 心情管理 → 题库 → **导入题库**，接受这样的 JSON 文件：

```json
{
  "schema": "siyuan-mood-bank",
  "version": 1,
  "name": "我的题库",
  "questions": [
    {
      "id": "my-1",
      "dimension": "body",
      "type": "single",
      "text": "此刻我的肩膀是：",
      "options": [
        { "id": "A", "label": "松的", "score": 3, "tags": ["身体放松"] },
        { "id": "B", "label": "有点绷", "score": 1, "tags": ["紧绷"] }
      ]
    }
  ]
}
```

- `dimension` 必须是 `body` / `recognition` / `energy` / `avoidance` / `need` 之一；`need` 不计分，只产出关键词。
- `score` 取 0-3，越大表示此刻越平稳、觉察越在线；`tags` 会成为关键词候选。
- `id` 与内置题相同的题会覆盖内置题。

## 设置项

- **每次题量**：5 / 8 / 10 / 12 / 15 题。
- **题库**：内置题库开关、导入题库开关、导入与导出。
- **复测提醒**：总开关、基础/最短/最长间隔天数、免打扰时段。
- **AI 解读**：总开关、提交后自动解读、提示词里带几次历史、追加提示词。
- **数据**：导出全部数据、导入数据、清空记录。

## 开发

```bash
pnpm i
cp .env.example .env   # 把 VITE_SIYUAN_WORKSPACE_PATH 设成你的工作空间
pnpm dev               # 监听构建，产物直接进 <工作空间>/data/plugins/siyuan-mood
pnpm build             # 生产构建 + package.zip
pnpm typecheck         # vue-tsc --noEmit
```

目录结构与实现分期见 [`docs/设计文档.md`](./docs/设计文档.md)。
