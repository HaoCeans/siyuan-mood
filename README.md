# AI 心情管理

一个装在思源里的心情记录插件——但它真正想做的，是**一个越用越了解你的 AI**。

你大概会想：这些事我直接问网页版的 AI 不就行了？

还真不行。网页 AI 每次对话都从零开始：你上周什么状态、它给过你什么建议、你试了有没有用，它一概不知道，只能给一些谁问都一样的通用答案。这个插件补上的恰恰是这一块——**你的情绪史就存在本地，每次解读都整段带给 AI**：

- **它读你的连续变化**：最近几次测评的分数与维度、一天内随手打卡的细轨迹、你绑定的笔记内容，全在提示词里
- **它记得每条建议的下场**：你标了「做了 / 没做」、做完心情打几分、卡在哪，下次解读原样带回
- **有效的方法会被沿用**：打分高的建议说明对你管用，AI 会往这个方向继续给；没做成的，换成门槛更低的起步版本
- **它拿你的现在和过去比**：「回避连续第三次满分」「下午打卡从平静滑到疲惫」——这种话，只有看过你记录的 AI 才说得出

一句话：**网页 AI 是个每次见面的陌生专家，这个插件养的是一个跟着你变熟的教练。**

## 「越用越懂你」是怎么发生的

每条记录都在走一个闭环：

```
答题 → AI 解读（自动带上你最近的历史和打卡轨迹）
  → 得到 2 条建议 + 1 个练习
  → 过一两天回来打勾：做了没？做完心情几分？卡在哪？
  → 反馈写回记录
  → 下次解读，AI 看着这些反馈调整方向
```

AI 在每次解读时实际能看到的内容，长这样（真实格式，非示意）：

```
<历史记录>
9/25 08:12｜心情分 67｜维度 情绪识别 55 / 能量 40｜关键词 加班、紧绷
 上次的建议与执行情况：
  · 睡前把手机放客厅充电 —— 做了（之后心情 4/5，感受：居然更容易睡着了）
  · 下班路上听十分钟白噪音 —— 没做（卡在忘了）
</历史记录>
```

那条「睡前把手机放客厅充电」之后心情 4/5——对 AI 来说，这就是**被你验证过的有效做法**，往后的建议会优先往这类方向靠；而「没做（卡在忘了）」意味着这条对你门槛太高了，下次会换一个更容易开始的版本。

你自己想到的做法也一样被跟进（会标注「他自己写的」一起交给 AI）。说到底，**最管用的建议往往不是 AI 凭空想出来的，是它从你的反馈里筛出来的。**

> 反馈不怕「差评」。标「没做」不是失败，它告诉 AI：这条对你来说太大了，换个小的。

## 怎么用

### 第一次：花一分钟答 10 道题

点顶栏那颗心，或者侧栏面板上的「开始问答」。一道道选最像此刻的选项，凭第一感觉选就行，没有对错。

**最后还有几步收尾**，都不计分、都可以跳过：

- **两道填空**——"自己感觉目前是什么状态"和"可能是什么事情影响的"。你写的话会一起交给 AI 看。
- **给此刻的情绪起个名字**——从「平静 / 有点烦 / 委屈 / 疲惫 / 说不上来……」里挑一个，或自己写。给情绪一个名字这个动作本身就有安抚作用（心理学上叫「情绪标注」），说不上来也是有效的记录。
- **勾几项最近的身体信号**——睡眠、食欲、动力、想不想说话。这些信号常常比情绪本身更容易觉察。

点「提交并解读」，AI 会把你的填空、名字、信号、作答，连同你的历史记录放在一起看。

### 等几秒，看 AI 怎么说

一句话的状态概括、几个关键词、2 条「十分钟内能做完」的小动作、一个这几天可以试的练习；从第二次起还会告诉你**和上次比哪里变了、上次哪条建议有效、哪条卡住了**。

### 过一两天回来打个勾（这步最有用，整个闭环靠它转起来）

点开那条记录，在每条建议下面选「做了 / 部分做了 / 没做」：

- 选**「做了」**：会问你做完之后心情几分（1-5），可以再写一句真实感受
- 选**「没做」**：会问你卡在哪（忘了 / 太难 / 不想做 / 没时间）

然后点「解读跟进」，AI 会复盘哪条建议真的有用、哪条卡住了、下次换成什么。**你的每一条反馈都会在之后的每次解读里被读到。**

**AI 给的建议可能都不适合你。** 做法清单下面有「＋ 自己想到的做法」，把自己真正打算做的写进去——它会和 AI 的建议一样被跟进、一样进复盘，下次解读也会一起交给 AI（标注为"他自己写的"），AI 会围绕你自己那条调整后面的建议。

### 攒几条之后，去「统计」看看

侧栏面板切到「统计」页：平均分、连续记录天数、建议执行率；带渐变面积的心情曲线；**星期分布**（哪天状态好、哪天最差，一眼看出）；几个方面的雷达对比；可翻月的心情日历；最常出现的关键词；最近两周的快速打卡带；还有一张 AI 生成的阶段小结（可选）。

## 三个入口

| 在哪 | 干什么 |
|---|---|
| 顶栏的心形图标 | 点一下就开始答题；有到期提醒时会亮个小红点 |
| 右侧边栏的「心情」面板 | 看记录卡片、统计、表格 |
| 命令面板（`Ctrl+P` / `⌘P`）搜「开始问答」 | 习惯用键盘的话 |

手机上：没有侧栏面板，用顶栏那颗心就行；答题和记录详情都会占满整屏。

## 随时记一笔（不用答题）

正式答题不该太频繁，但一天里心情的变化值得随手记。侧栏面板顶部有个「**记一下此刻**」按钮（快捷键 `⌥⌘M`，可在 设置 → 快捷键 里改）：点开一排情绪词，**点一下就存好了**，几秒钟的事。

- 早上记一个「平静」，中午记一个「累」，晚上再记一个——这就是你一天的情绪轨迹
- 每记一条，下面会冒出一句**根据最近轨迹生成的 AI 小建议**；没配 AI 也会给一句通用的
- 这些细轨迹会在下次答题时一起交给 AI，它能看出「早上平静、下午总是烦」这种一天内的模式
- 统计页里有「快速打卡」区：最近两周每天一条彩色时间带，还有词频

## 关于 AI（想省事先看这段）

插件**不提供、也不代理任何 AI 服务**，它直接用思源自己的 AI 通道——也就是你在 `设置 → AI` 里配好的那一个。所以：

- 思源里已经配了 AI → 直接能用，不用再在插件里配一遍
- 思源里还没配 → 答题、记录、统计全都正常，只是没有解读；点解读时会提示你去配置
- 怎么配：`设置 → AI` 里加一个模型服务，填 API Key、接口地址、模型名（OpenAI 兼容的都可以，比如 DeepSeek、Kimi、通义这些）
- 你的记录只存在自己的工作空间里，AI 请求只发往你自己配置的那个模型

**AI 能看到多少历史？** 每次解读带最近几次测评的完整对比（含每条建议的执行情况和你的打分），默认 3 次，可在 `设置 → AI心情管理 → 提示词里带几次历史` 里调到最多 10 次；最近几条快速打卡会作为一天内的细轨迹一起带上。

## 常见问题

**每次只能 10 题吗？**
可以改：`设置 → AI心情管理 → 每次题量`，能选 5、8、10、12 或 15 题。

**能不能不用 AI？**
可以。`设置 → AI心情管理 → AI 解读` 关掉即可，记录和统计不受影响。

**提醒太频繁、太吵？**
设置里能关掉提醒、改间隔天数。默认一周一次，而且算法再怎么调整，最快也只会到三天一次——觉察是慢功夫，触发太勤反而变成负担。免打扰时段默认 22:00–08:00，那段时间只亮红点不弹提示；嫌烦就点「今天不再提醒」。

**记录会丢吗？能同步到手机吗？**
记录都写在你自己的工作空间里，跟着思源的同步一起走（开了同步的话）。随时可以在 `设置 → AI心情管理 → 数据` 里导出成一份 JSON 备份。

**怎么删掉某条记录？**
点开那条记录，拉到底部有「删除这条记录」，点两下确认。

**我想用自己的题目。**
`设置 → AI心情管理 → 题库 → 导入题库`，格式见下一节。

## 自己出题（进阶，不看也完全能用）

不用写代码，也不用懂什么格式。**写一个 Markdown 文件就行**——在思源里新建一篇文档，照下面这样写，然后导出成 `.md`（或者用任何文本编辑器写一个 `.md`）：

```md
## 此刻我的肩膀是
- 松的
- 有点绷
- 很紧

## 此刻你的能量水平
- 有精神
- 一般
- 很累
```

然后打开 `设置 → AI心情管理 → 题库 → 导入题库`，选中这个文件。插件会先把题目和选项认出来，**如果你配了 AI，它还会再整理一遍**：判断每道题属于哪一类、每个选项该给几分、提取关键词。整理完会弹出预览让你看一眼，点「保存这份题库」才生效。

写题的三条小建议：

- **题干用 `## 标题` 或 `1. 题干` 开头最稳妥**，选项每行一个、用 `-` 开头
- 选项按「从好到差」的顺序写，插件默认第一个选项分数最高（配了 AI 的话由 AI 判断）
- 想让某道题可以多选，在题干里写上「可多选」；想要一道填空题（用户自己写一句话），在题干里写上「填空」或「自己说」即可，不用写选项

导入的题目会和内置题库合并使用。想看看现在共有哪些题，点同一个设置页里的「查看当前题库」；想整体不用内置题，把「使用内置题库」关掉即可。（「导出题库」导出的是 JSON 格式，可以直接再导入回来，也可以手写它来覆盖某道内置题——把 `id` 写成和内置题一样的就行。）
